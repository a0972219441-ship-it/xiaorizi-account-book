Android 安裝說明

解壓縮 ZIP，把 index.html、manifest.webmanifest、sw.js、icon.svg 上傳到 GitHub 儲存庫根目錄。到 Settings → Pages，選 main 與 /(root) 啟用。網站部署後用 Chrome 開啟，再從 ⋮ 選「加到主畫面」或「安裝應用程式」。需 HTTPS 網址。

尚未實作：銀行／券商自動同步、即時 ETF 行情、跨裝置同步、信用卡到期提醒與貸款攤還表。
